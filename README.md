# 👗 WA MORGAN FASHION

This is a responsive e-commerce web application built for a premium fashion and clothing brand. I built this to practice creating clean product layouts, navigation menus, and a smooth shopping experience across mobile and desktop devices.

🔗 **[View the Live Site Here](https://vercel.app)**

---

## 🛠️ Built With
- React.js & JavaScript
- CSS (Responsive Layouts)
- Deployed on Vercel

---

## 🚀 How to Run it Locally

If you want to download and run this project on your own machine:

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Install the project packages:
   ```bash
   npm install
   ```
3. Start the local server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.
